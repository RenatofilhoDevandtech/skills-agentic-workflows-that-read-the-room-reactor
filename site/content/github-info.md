## Featured Agentic Workflows

Explore practical automation from the [awesome-copilot workflows](https://awesome-copilot.github.com/workflows/) collection:

- **Relevance Check:** Use a slash command to have AI evaluate if older issues or pull requests are still relevant to the project's current state.
- **Weekly Comment Sync:** Automatically identifies stale code comments and README snippets, then drafts pull requests to synchronize them with the codebase.
- **Daily Issues Report:** Generates a daily summary of open issues and recent activity, posting it as a consolidated GitHub issue for team visibility.
